# The Flamiingo Kid

A visual music hub connecting listeners to releases, music videos, and the FLAMIINGO shop.

## Features

- Full-screen snap-scrolling slides
- Release and video links
- Responsive artwork presentation
- Social sharing metadata
- Accessible link labels

## Built With

- HTML
- CSS
- JavaScript

## Requirements

No Node.js installation is required.

## Run Locally

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/Miingo954/the-flamiingo-kid.git
cd the-flamiingo-kid
open index.html
```
